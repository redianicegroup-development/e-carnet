# Prototypes — référence visuelle uniquement

Les prototypes HTML conservés ici illustrent une direction visuelle mobile : navigation compacte, proportions, hiérarchie, cartes, palette et iconographie. Ils sont archivés en lecture seule et ne sont pas importés dans l’application.

**Ils ne sont plus la source de vérité des parcours.** Certains flows sont anciens; les décisions et flows à jour sont dans les [roadmaps produit V1–V5](../ROADMAP-V1-V5.md) et le [journal A1–A16](../QUESTIONNAIRE-DECISIONS-A1-A16.md). En cas de divergence, ne pas réintroduire un ancien parcours de maquette.

L’application peut adapter proprement l’expérience à l’écran desktop, tout en visant une navigation, densité et lisibilité proches du mobile prototype. Voir aussi [l’audit du code et du design](../RAPPORT-AUDIT-ECARNET.md).
